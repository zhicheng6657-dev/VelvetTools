三、管理员权限

安装程序会请求 Windows UAC 管理员授权，仅用于：

1. 把程序写入 Program Files；
2. 创建开始菜单、桌面快捷方式和“应用和功能”卸载信息；
3. 在你主动勾选时，创建名为“VelvetTools”的按需计划任务，使应用以后能够以最高权限运行。

最高权限运行不是强制选项，可在安装时不勾选，也可在软件设置中关闭。卸载程序会删除
该计划任务。“随 Windows 登录自动启动”也是独立选项：普通权限模式使用当前用户启动项，
最高权限模式使用计划任务的登录触发器。Velvet Tools 不安装或加载第三方内核驱动。
温度功能只读查询 Windows/显卡驱动公开接口，以及用户已自行运行的监控工具所公开的 WMI；
不会下载、启动或控制这些监控工具及其驱动。

四、数据与在线服务

设置、API 密钥、对话和知识库默认保存在本机 %AppData%\VelvetTools。在线 AI、翻译、
OCR 或搜索功能只会把完成相应请求所需的数据发送给你自行选择和配置的服务商。
卸载时默认保留用户数据，以免误删对话和知识库；如需彻底清理，可在确认备份后手动删除
%AppData%\VelvetTools。

这是 Beta 0.01 预发布版本，可能包含缺陷或尚未覆盖的硬件兼容问题。请在重要工作前备份
数据。安装包当前未使用商业代码签名证书签名，Windows SmartScreen 可能显示“未知发布者”；
请只从项目正式 GitHub Releases 页面下载并核对 SHA-256。
